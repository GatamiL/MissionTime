# Mission Time 🚀📅

**Mission Time v2.0** — это современное десктопное приложение на базе WPF для автоматизированного учета рабочего времени сотрудников, распределения трудозатрат по проектам и генерации высокоточных Excel-отчетов.

## ✨ Ключевые возможности

*   **Modern UI (WPF):** Полностью переработанный интерфейс с кастомным дизайном, плавной анимацией и поддержкой современных стандартов Windows.
*   **Умный табель (DataGrid):** Единое окно для редактирования часов с интеллектуальным вводом (автодополнение времени, проверка корректности).
*   **Excel-совместимость:** Поддержка копирования данных напрямую из Excel (Ctrl+C / Ctrl+V) с автоматическим форматированием.
*   **Сверхбыстрая навигация:** Мгновенный поиск по фамилии — просто начни печатать, и фокус переместится на нужную строку.
*   **Иерархия подразделений:** Поддержка сложной структуры организации (Центры -> Комплексы -> Отделы).
*   **Генерация Excel-отчетов:**
    *   Сводные данные по отделам и комплексам.
    *   Динамический расчет высоты ячеек (текст всегда виден полностью).
    *   Рекурсивная агрегация данных через SQL (CTE).
*   **Надежное хранение:** SQLite с автоматической валидацией схемы, миграциями и системой резервного копирования.

## 📦 Портативность (Single File EXE)
Приложение собрано как **Self-Contained Single File**. 
*   **Все в одном:** Все зависимости (.NET Runtime, EPPlus, SQLite) вшиты в один `.exe`.
*   **Portable:** Не требует установки .NET или сторонних библиотек. Просто запустите и работайте.
*   **Размер:** ~50 МБ (включая всю среду исполнения .NET).

## 🛠 Стек технологий

*   **Язык:** C# 12
*   **Платформа:** .NET 8 (WPF)
*   **Архитектура:** MVVM (Model-View-ViewModel)
*   **База данных:** SQLite (System.Data.SQLite)
*   **Работа с Excel:** EPPlus (v4.5 — non-commercial)
